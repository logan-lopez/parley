# Widget hints

## Choice

`x-widget` (and other `x-*` keys) inside the JSON Schema. The model never writes a JSON Forms UI schema.

## Why

UI schemas are verbose. The testers match on `x-widget`, and JSON Forms lays out the rest ([form spec](../architecture/form-spec.md#decisions)).
