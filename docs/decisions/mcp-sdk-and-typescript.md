# MCP SDK and TypeScript

## Choice

MCP TypeScript SDK v2 (`@modelcontextprotocol/server`, Zod 4), not `@modelcontextprotocol/sdk` 1.x. TypeScript ~6.0.

## Why

The TS SDK is the most complete one. vue-tsc was scaffolded against TS 6; TS 7 is `latest` on npm.
