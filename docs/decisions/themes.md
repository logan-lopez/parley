# Themes

## Choice

inn's format (base16/base24 YAML with `overrides`, inn's token names), set as `theme` in `~/.config/parley/settings.json`: one id, or `{ light, dark }` following the macOS appearance live. Reads `~/.config/inn/themes/` in place and `~/.config/parley/themes/`. No settings page. Parley Light and Dark reproduce the old colors and are the default pair.

## Why

One theme file serves inn, Quire and Parley, and the pair's contract is written to be copied back into inn and Quire (Logan, 2026-10-12, brief 15).
