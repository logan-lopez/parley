# UI stack

## Choice

Vue 3 (Composition API, `<script setup>`), JSON Forms 3.x Vue bindings, the three `@jsonforms/*` at the same exact version

## Why

JSON Forms renders arbitrary JSON Schema with custom renderers picked by testers, which is what a raw-schema `ask_form` will need ([the card](../architecture/card-ui.md)).
