# Shell

## Choice

Tauri 2, with capabilities-based permissions (not the Tauri 1 allowlist). The Rust side stays small: tray, hotkey, window, socket hub.

## Why

Official plugins cover the tray, hotkey, notifications and file dialog, and the UI is web tech, so the same card ships as an MCP Apps view ([desktop shell](../architecture/desktop-shell.md)).
