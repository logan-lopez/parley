# How Parley works

Parley as you use it, one page per feature. It describes what works now. What's planned is in the
briefs (`docs/briefs/`), and how the code is built is in `docs/architecture/`.

Start with [The app](the-app.md): everything else happens in its window or beside it.

- [The app](the-app.md): the tray, notifications, the window and its hotkey, zoom.
- [Answering a card](answering.md): the queue, picking and sending, copying code, skipping, the
  note for the agent, and asks that end under you.
- [Question types](question-types.md): choice, text, number, yes/no, path, review and capture,
  as you see them.
- [From Claude Code](claude-code.md): what happens while an ask waits, long asks, Esc, and the
  built-in question tool.
- [From Claude Desktop](claude-desktop.md): the inline card in the chat, and how it races the
  window.
- [History](history.md): every ended ask, filters, the detail view, drafts and clearing.
- [What it looks like](screenshots.md): the window, and every kind of card in light and dark.
- [Installing and setting up](installing.md): the app, the server, and registering it in Claude
  Code, Claude Desktop and Codex.
